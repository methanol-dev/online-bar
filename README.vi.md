## 🌟 Tổng Quan

**Bar Online (Vũ Trường 88)** là phần mềm vũ trường ảo tương tác thời gian thực cao cấp dành riêng cho **TikTok Live (chuẩn khung hình dọc 9:16 / 1080x1920)** và **OBS Studio**.

Hệ thống tự động chuyển hóa các tương tác của người xem trên TikTok (bình luận, thả tim, gửi quà, chia sẻ) thành một vũ trường 3D điện tử rực rỡ với **hàng nghìn nhân vật người que nhảy múa mang avatar Meme thực tế từ Internet**, phát nhạc đồng bộ từ **YouTube** hoặc **file MP3 tải lên**, kết hợp hệ thống đèn moving head laser, pháo hoa và hiệu ứng quà tặng siêu xe Lamborghini, trực thăng, tên lửa và vương miện hoàng gia.

### 🎵 2. Trung Tâm Phát Nhạc Đa Nguồn (Multi-Source DJ Music Hub)

### 🍱 4. Bảng Điều Khiển Streamer Control Center 2.0 (Bento Grid)
- **Màn Hình Xem Trực Tiếp (Live Mini Monitor)**: Preview màn hình stream 9:16 ngay trên Dashboard.
- **DJ Soundboard 8 Phím Tắt**: Còi bar hú (Airhorn), Cào đĩa (Scratch), Đếm ngược 3-2-1, Bass Drop, Khui Sâm Panh, Thổi còi, Tiếng la hét.

### ⚡ 5. Hiệu Năng Vững Vàng 60 FPS Cho 3.000 Dân Chơi

### 🤖 6. AI Live Pilot Agent (Khởi Động 1 Chạm)

## 🚀 Hướng Dẫn Cài Đặt & Sử Dụng

### Yêu Cầu Hệ Thống
- [Node.js](https://nodejs.org/) phiên bản 18 trở lên
- [OBS Studio](https://obsproject.com/) (hoặc TikTok Live Studio)

### 1. Cài Đặt

```bash
# Clone mã nguồn
git clone git@github.com:methanol-dev/online-bar.git
cd online-bar

# Cài đặt các gói phụ thuộc
npm install
```

### 2. Khởi Chạy

#### Cách 1: Chạy 1-Click trên Windows (Tiện nhất)
Click đúp file [`START_BAR_LIVE.bat`](START_BAR_LIVE.bat).

#### Cách 2: Chạy Bằng Lệnh
```bash
npm start
# hoặc chạy trợ lý tự động:
node scripts/autopilot.js
```

### 3. Cài Đặt OBS Studio (Tỷ Lệ Dọc 9:16)
1. Trong OBS Studio, vào **Settings** ➔ **Video**:
   - **Base Resolution**: `1080x1920`
   - **Output Resolution**: `1080x1920`
   - **FPS**: `60`
2. Trong bảng **Sources**, bấm `+` chọn **Browser**:
   - **URL**: `http://localhost:3000`
   - **Width**: `1080`
   - **Height**: `1920`
   - Tích chọn: `Control audio via OBS` & `Shutdown source when not visible`.
3. Mở trình duyệt vào **`http://localhost:3000/dashboard`** để bắt đầu livestream và điều khiển!
